# OATP1B1_OATP1B3_BCRP
Ингибиторы транспортеров OATP1B1/OATP1B3 и BCRP: молекулярные механизмы, лекарственные и нутрицевтические взаимодействия, клинические ограничения
Ингибиторы транспортеров OATP1B1/OATP1B3 и BCRP
Молекулярные основы и клиническое значение
Розувастатин представляет собой чувствительный комплексный зонд транспортной сети печеночного захвата (OATP1B1/OATP1B3) и эффлюкса (BCRP), но не является селективным инструментом для количественной оценки отдельной изоформы. Изменение его плазменной экспозиции отражает совокупность:

кишечного всасывания

поступления в гепатоциты

билиарного и почечного выведения

Ингибирование CYP3A само по себе не объясняет взаимодействия розувастатина с усиленными схемами антиретровирусной терапии.

Период отмывки
Общего правила для фиксированного периода отмывки для всех ингибиторов OATP1B/BCRP не существует.

Для колхицина: 14 дней после завершения приёма ингибитора

Для фузидовой кислоты: 7 дней после прекращения

Разнесение на 2–4 часа не является универсальным решением

Для обратимого ингибитора с элиминацией первого порядка остаточная концентрация после n периодов полувыведения: 2<sup>−n</sup> исходной. После 5 периодов остаётся ≈3.1%, что может сохранять ингибирующее действие при высоком исходном отношении I<sub>u</sub>(0)/K<sub>i</sub>.

Ключевые выводы
Розувастатин — интегральный зонд транспортной сети, а не селективный маркер отдельной изоформы.

Двойная блокада OATP/BCRP — важный, но не универсальный механизм; капматиниб демонстрирует клинически значимое взаимодействие без ингибирования OATP in vitro.

Генетические и лекарственные эффекты нельзя перемножать; остаточный клиренс представляет собой сумму параллельных путей.

Нутрицевтические взаимодействия требуют оценки конкретного продукта, дозы, состава и режима приёма; данные in vitro не заменяют клинических исследований.

Период отмывки индивидуален и зависит от конкретного сочетания; универсальные правила отсутствуют.

Регуляторные ограничения различаются по юрисдикциям (США vs EMA) и редакциям документов.
